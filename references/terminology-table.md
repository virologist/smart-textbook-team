# 全书术语一致性表（terminology table）

> **本文件是「同一概念只能用一种写法」的权威源**。
> examiner R4（风格审查）+ 门禁 4.11（术语门禁）以本文件为准。
>
> **2026-10-30 批次 C2 补建**：此前全包 grep「术语表」= 4 处「（如有）」式引用，
> 但**包内根本没有这张表**，而 citation-verify 只管引用真伪、不管术语统一——
> 结果「PMID 真实但术语混乱」这一类问题在交付层无人看守。

## 1. 填表规则

| 列 | 含义 | 规则 |
|---|---|---|
| **标准写法** | 全书唯一写法 | 必须是**首次出现时的完整形式**；不得用缩写代替 |
| **允许别名** | 可接受的其他写法 | 仅在**上下文已给出标准写法之后**才允许；同一页内不并存 |
| **禁用写法** | 明确禁止 | 如「禽流感（AI）」——缩写歧义过大 |
| **首次出现位置** | 章节号 | 标注该术语在本书首次出现处（用于回查） |
| **来源** | 依据 | 标准名/权威源（如 ICTV、兽药典、GB/T、课程标准） |

## 3. 门禁 4.11 判据（可执行；SSOT = check_manuscript.py `check_terminology` 实现口径）

| # | 判据 | 口径 | fail 处置 |
|---|---|---|---|
| 4.11a | **禁用写法零出现** | 全文出现「禁用写法」列任一写法 → 计数；**纯 ASCII 词用词界匹配**（"AI" 不得命中 "AIV"），含中文词用子串 | 回 writer 修正 |
| 4.11b | **同概念多写法未并存** | 同一章内「标准写法」与「允许别名」**各自独立出现** → 计数。独立 = 别名出现位置**未被**标准写法出现区间覆盖（长形式里的一截不算并存）。**包含关系豁免**：`标准写法 ⊂ 别名` 或 `别名 ⊂ 标准写法` 时字符串层无法区分"独立出现"与"长形式片段"，4.11b 降级为 advisory，在 detail 列 `包含关系豁免 4.11b` 声明不外判 | 回 writer 统一 |
| 4.11c | **首次出现位置正确** | 当前章号 < 表声明「首次出现」章号 且该术语在正文出现 → 计数。声明为 `—`/无法解析 → N/A。（P2-5 补实现：此前只有判据声明、脚本零实现） | 回 writer 调整表述（首见给全称）或按真实首见修正表列（见 §2 口径） |
| 4.11d | **表内标准写法唯一** | 同一「标准写法」多行 → 计数（E 补口径：此前 §5 引用了 4.11d 但此处无定义——现补齐，实现于 `check_terminology` 的 dup 统计） | 回 examiner 合并重复行 |

> **术语一致性 ≠ 缩写一律展开**：教材中 ND/IBD 等标准缩写属**正确用法**，
> 关键约束是「**首次出现给全称 + 之后统一用缩写**」，而非全文禁用缩写。

> **填表铁律（P1-2 实战教训）**：
> 1. **别名列只放别名本身**，不要塞说明文字（如「（首见全称）」）——该列是机器解析字段，
>    混入说明会让判据去正文找一句永远不会出现的字符串，形成"永远查不到 = 永远通过"的假绿。
> 2. **能避则避包含关系**：若短形式是长形式的子串（`H9N2 亚型` ⊂ `H9N2 亚型禽流感病毒`），
>    4.11b 会被豁免（见上表），此时该条术语的一致性**只能靠人眼**。真需要强约束时，
>    把短形式写成**不可子串化**的独立项（如单独一行 `H9N2 亚型病毒`）或依赖 4.11a 禁用列兜底。

## 5. 维护约定

- **新增术语**：每章 DELIVER 后，examiner 把该章新出现的术语追加进本表（**待定行**：标准写法待定）。
- **合并**：同一标准写法的多行合并；**不得留重复行**（门禁 4.11d 校验行内标准写法唯一）。
- **归档**：跨章重复检查由 `scripts/check_cross_chapter.py` 兜底（术语别名维度）。
