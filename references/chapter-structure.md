# 章节结构规范（chapter structure standard）

> **本文件是「章节应有结构」的唯一权威源（SSOT）**。
> examiner R1（结构审查）、didactic-architect（设计产出）、writer（撰写）三方的结构判据
> 全部以本文件为准；**任何地方不得另行硬编码结构清单**。
>
> **2026-10-30 批次 C1 补建**：此前全包 grep「八要素/学习目标/导入案例/五维/评分/80分」
> = **0 命中** —— 章节结构判据完全散落在成员 MD 的散文描述里，
> 导致「章节结构是否合规」这一最基本的命题**无任何可执行判据**。

## 0. 加载协议

1. **学科 profile 优先**：若 `references/profiles/{discipline}.md` 含 `§5 章节结构` 段，
   该段**覆盖**本文件的默认值（仅覆盖结构项，不覆盖质量红线）。
2. **未声明 discipline** → 用本文件默认（职业本科金教材口径）。
3. **profile 缺失** → 回落默认并在 examiner 的 `issues` 中声明，**不静默换标准**。
4. **外部标准注入**：用户提供的课程标准/教学大纲可作为第 4 优先级（低于 profile），
   但**只作判据不作内容来源**（与门禁 3.5 同纪律，见 pipeline §外部学科规范注入协议）。

> 优先级：`profile §5` > 本文件默认 > `{WORK_ROOT}/学科标准/*.md`（用户注入）

## 1. 八要素结构（默认口径 · 职业本科金教材）

每章**必须**包含以下 8 个要素，缺一即 R1 结构审查 **FAIL**：

| # | 要素 | 必备性 | 最小内容要求 | 常见误用（判 FAIL） |
|---|---|---|---|---|
| 1 | **学习目标** | 必备 | 知识 + 能力 + 素质三维标注，各 ≥1 条；可映射 Bloom 层级 | 只写「掌握本章知识」这类空话 |
| 2 | **导入案例** | 必备 | 一个真实情境案例（可标 `[待核实]`），引出本章问题 | 与学习目标无关的装饰性故事 |
| 3 | **理论知识** | 必备 | 本章知识主线，**必须挂 `章节/{ch##}/sections/` 的节级文件**（见 §3） | 只有结论无机制解释 |
| 4 | **防治措施** | 必备 | 四位一体：预防 / 治疗 / 控制 / 综合防控（各 ≥1 条） | 只写「加强饲养管理」 |
| 5 | **实践操作** | 必备 | SOP 形态：操作目的 / 器材 / 步骤 / 安全 / 评价标准（**安全项不可缺**） | 缺安全提示 |
| 6 | **案例分析** | 必备 | ≥1 个案例（典型 ★ / 复杂 ★★ / 警示 ★★★ 难度分级） | 与导入案例重复 |
| 7 | **思考与练习** | 必备 | 梯度题（认知层级递进），含 `[习题 {章}-{序}]` 标记 | 全部同层级题 |
| 8 | **拓展阅读** | 必备 | 前沿技术 / 行业动态 / 职业发展 之一以上，带来源 | 空占位 |

> **判据可执行性**：examiner R1 必须逐要素核对「标题存在 + 最小内容要求满足」，
> 不得以「章节看起来完整」放行。

## 2. 五维质量评分（默认口径）

R4 之后追加 **R5 质量评分轮**（见 `agents/quality-examiner.md`）。评分维度与权重：

| 维度 | 权重 | 判据要点 |
|---|---|---|
| 知识严谨性 | 30% | 每个数据点可溯源（`[实]` 且标识符经核验）；无「看起来合理但无源」的数据 |
| 前沿性 | 15% | 引用近 10 年为主（≥80%）；经典文献可作例外 |
| 易懂易学 | 25% | 学段适配（段落 ≤200 字、抽象概念有实例锚点、先 How 后 Why） |
| 职业教育适配 | 20% | 岗课赛证融通：真实工作任务 / 1+X 证书 / 技能大赛点 / 行业标准对应 |
| 规范性 | 10% | 术语统一（对照 `references/terminology-table.md`）、格式合规、编号连续 |

**红线**：**总分 < 80 分 = blocking**，不得交付（与 `skills/manuscript-delivery` 的交付门禁并列）。

> **降级纪律**：若评分依赖的外部脚本不可用（如 `quality-check.py` 缺失），
> 改由 examiner 按本表**逐维 LLM 评分**并在 `issues` 中声明「脚本缺失，已降级为 LLM 评分」；
> **不得静默跳过本轮**。

## 3. 节级颗粒度推进（与 §1.3 呼应）

- 章节**字数目标 > 8000 字** → **强制**按节推进（`章节/{ch##}/sections/{节号}.md`），
  不得整章一次性撰写后直接进审查（上下文必然裁剪、审查颗粒过粗）。
- 节级推进顺序：节级撰写 → **节级自查**（标签/编号/字数/交叉引用）→ 文件级拼接为
  `draft.md` → 整章 R1-R4 审查。
- 拼接必须记录来源节号（便于回溯与返修定位）。

> 判据：examiner R1 应能核到 `sections/` 目录下的节级文件；
> 大章节若只见整章 draft 无节级文件 → R1 advisory（记录「建议节级推进」）。

## 4. 鉴别诊断类章节的附加要求

若本章属「鉴别诊断模块」（而非疾病个论），额外要求：

- **个论不重复原则**：病原分子机制 / 血清型逐一列举 / 完整基因组结构 / 完整防治体系
  → 改为「详见《XX》[疾病名]节」引用格式，**不得在鉴别模块重复个论内容**。
- **三切入口**：横向鉴别入口 / 场景决策入口 / 综合防控入口，至少覆盖其一。
- **推理链**：重点疾病嵌入 Mermaid 推理链，节点标注**临床依据**（不是抽象描述），
  判断节点 4-8 个。

## 5. 平台 / 模板差异说明

- **高职专科**：可裁掉要素 8（拓展阅读）与要素 4 的部分细分，但要素 1/2/5/7 **不可裁**
  （这是「能做」与「看懂」的分界）。
- **职业本科**：八要素全备，且要素 4「防治措施」需体现**岗位胜任**维度。
- **研究生 / 专著**：可裁要素 2/6，但需补「研究前沿」与「方法学」说明。

> 上述裁剪只影响「必备性」，**五维评分与 80 分红线在任何学段都不豁免**。
