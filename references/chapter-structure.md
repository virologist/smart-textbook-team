# 章节结构规范（chapter structure standard）

> **本文件是「章节应有结构」的唯一权威源（SSOT）**。
> examiner R1（结构审查）、didactic-architect（设计产出）、writer（撰写）三方的结构判据
> 全部以本文件为准；**任何地方不得另行硬编码结构清单**。
>
> **2026-10-30 批次 C1 补建**：此前全包 grep「八要素/学习目标/导入案例/五维/评分/80分」
> = **0 命中** —— 章节结构判据完全散落在成员 MD 的散文描述里，
> 导致「章节结构是否合规」这一最基本的命题**无任何可执行判据**。

## 0. 加载协议

1. **学科 profile 优先**：若 `references/profiles/{discipline}.md` 含 `§5 章节结构` 段，
   该段**覆盖**本文件的默认值（仅覆盖结构项，不覆盖质量红线）。
2. **未声明 discipline** → 用本文件默认（audience-profiles 默认档·金教材口径）。
3. **profile 缺失** → 回落默认并在 examiner 的 `issues` 中声明，**不静默换标准**。
4. **外部标准注入**：用户提供的课程标准/教学大纲可作为第 4 优先级（低于 profile），
   但**只作判据不作内容来源**（与门禁 3.5 同纪律，见 pipeline §外部学科规范注入协议）。

> 优先级：`profile §5` > 本文件默认 > `{WORK_ROOT}/学科标准/*.md`（用户注入）

## 1. 章节结构（学科化 · B3/ADR-02）

R1 结构审查的「每章应含哪些要素」由**学科 profile §5.2 章节结构**承载（ADR-02 下沉，
原八要素已逐字搬入 `references/profiles/{discipline}.md §5.2`）。查找优先级：
`profile §5.2` > 本节通用兜底 > `{WORK_ROOT}/学科标准/*.md`（用户注入）。

**通用兜底四要素**（无 profile / profile 未声明结构时使用）：

| # | 要素 | 必备性 | 最小内容要求 |
|---|---|---|---|
| 1 | 学习目标 | 必备 | 知识 + 能力 + 素质三维标注，各 ≥1 条 |
| 2 | 导入案例 | 必备 | 一个真实情境案例（可标 `[待核实]`），引出本章问题 |
| 3 | 理论知识 | 必备 | 本章知识主线，挂 `章节/{ch##}/sections/` 节级文件（见 §3） |
| 4 | 练习 | 必备 | 梯度题（认知层级递进），含 `[习题 {章}-{序}]` 标记（书稿层唯一合法形式；设计层按节分配用 `[习题位 {节号}：…]`，落位时映射为全章流水号） |

> 学科扩展要素（如兽医的「防治措施 / 实践操作 / 案例分析 / 拓展阅读」八要素、鉴别诊断类
> 章节附加要求、学段裁剪细则）由 profile §5.2 承载，通用层不再写死（ADR-02）。
> **判据可执行性**：examiner R1 逐要素核对「标题存在 + 最小内容要求满足」，不得以
> 「章节看起来完整」放行。

## 2. 五维质量评分（默认口径）

R4 之后追加 **R5 质量评分轮**（见 `agents/quality-examiner.md`；轮次归属 SSOT 见 pipeline §轮次归属——R4+R5 属 PROOFREAD 态）。评分维度与权重：

| 维度 | 权重 | 判据要点 |
|---|---|---|
| 知识严谨性 | 30% | 每个数据点可溯源（`[实]` 且标识符经核验）；无「看起来合理但无源」的数据 |
| 前沿性 | 15% | 引用近 10 年为主（≥80%）；经典文献可作例外 |
| 易懂易学 | 25% | 学段适配（段落 ≤200 字、抽象概念有实例锚点、先 How 后 Why） |
| 职业教育适配 | 20% | 岗课赛证融通：真实工作任务 / 1+X 证书 / 技能大赛点 / 行业标准对应（**按 architect §B「职教融通规划」验收——规划缺项或规划与产出不对应即扣分，批次 F 生产端对接**） |
| 规范性 | 10% | 术语统一（对照 profile §5.1 术语表，三级查找）、格式合规、编号连续 |

**红线**：**总分 < 80 分 = blocking**，不得交付（与 `skills/manuscript-delivery` 的交付门禁并列）。

> **申报口径对接（批次 F，2026-10-31）**：本五维与教育部「十四五」职业教育国家规划教材
> 遴选原则（教职成厅函〔2025〕1 号）的对应关系——育人性→思政融入点（4.9）；
> 职业性→岗课赛证融通（职教适配 20%）；立体性→立体化资源位（architect §B）；
> 动态性→前沿性 15%；协作性→外部学科规范注入（pipeline §外部学科规范注入协议）。
> 申报材料另需：修订对照表、数字资源备案信息——属团队范围外，由用户侧整理。

> **降级纪律**：若评分依赖的外部脚本不可用（如 `quality-check.py` 缺失），
> 改由 examiner 按本表**逐维 LLM 评分**并在 `issues` 中声明「脚本缺失，已降级为 LLM 评分」；
> **不得静默跳过本轮**。

## 3. 节级颗粒度推进（与 §1.3 呼应）

- 章节**字数目标 > 8000 字** → **强制**按节推进（`章节/{ch##}/sections/{节号}.md`），
  不得整章一次性撰写后直接进审查（上下文必然裁剪、审查颗粒过粗）。
- 节级推进顺序：节级撰写 → **节级自查**（标签/编号/字数/交叉引用）→ 文件级拼接为
  `draft.md` → 整章 R1-R4 审查。
- 拼接必须记录来源节号（便于回溯与返修定位）。

> 判据：examiner R1 应能核到 `sections/` 目录下的节级文件；
> 大章节若只见整章 draft 无节级文件 → R1 advisory（记录「建议节级推进」）。

### 3.1 结构冻结点❄（B3，2026-11-04）

**定义**：examiner 的 **VERIFY-R1 结构审查 pass** 时刻，即为本章的「结构冻结点❄」。
此后本章的结构要素（§1 的必备要素 / §C 节序 / 图表位编号）视为冻结；
VERIFY-R2/R3 只做内容深化与数据核验，**不得再改结构**（确需改结构 ⇒ 回 R1 重审，
冻结作废并记 trace）。

**为什么需要它**：旧序把 VISUALIZE 全链后置，理由笼统写作「结构未稳定就出图会作废」。
B3 把该风险细化为可判定的时点：R1 pass 后结构变更概率大幅下降，
高变的只剩 R2/R3 的数据嵌入 ⇒ 允许绘章图在此刻基于**只读冻结稿**
`章节/{ch##}/draft_r1_frozen.md` 开 `VISUALIZE-spec`，与 R2/R3 并行。

**R1 判据不变**：本节 §1（四要素 / profile §5.2 / 学段裁剪）仍是 R1 的唯一判据，
B3 不新增结构项、不降低必备性、不豁免五维评分与 80 分红线。
主理人在 R1 pass 当轮 `cp draft.md draft_r1_frozen.md`（只读冻结，归属见
`references/path-ownership.md`）；后续图表位变更率由
`scripts/parallel_gate.py visual-drift` 机械裁决，`>50%` 自动回退旧串行序。
口径 SSOT = `skills/textbook-pipeline-workflow/SKILL.md` §搭接并行协议。

### 3.2 节依赖表 §C.1（B4，2026-11-04）

**定义**：`chapter_design.md` 除 §C 分节计划外，必须另出**机器可读的节依赖表**，
作为章内节级并行波次的唯一依据（由 didactic-architect 产出，编排者不代写）：

```markdown
<!-- SECTION_DEPS_BEGIN -->
| 节号 | strong-dep | no-dep | 关键术语 | 字数目标 |
| --- | --- | --- | --- | --- |
| 1.1 | — | yes | T1,T2 | 800 |
| 1.2 | 1.1 | no | T3 | 1200 |
| 1.3 | — | yes | — | 900 |
<!-- SECTION_DEPS_END -->
```

| 列 | 含义 | 硬约束 |
|---|---|---|
| `节号` | 本节节号 | 必须出现在 §C 分节计划里 |
| `strong-dep` | 依赖的上游节号（逗号分隔） | 引用的节号必须在表内；成环 ⇒ 拒收 |
| `no-dep` | 是否可并行 | `yes` 与非空 `strong-dep` **矛盾即拒收** |
| `关键术语` | 本节定义/首用的术语 | 逗号分隔；下游有强依赖时上游术语随派单注入 |
| `字数目标` | 本节净字数目标 | 必为正整数（调度器据此估 token） |

**语义边界**：

- `strong-dep` = **术语依赖**（该节用到的术语须先在上游节定义），**不是内容顺序依赖**；
  内容顺序由 §C 节序保证。
- **不得为凑并行度拆分有强依赖的知识块**——拆分粒度服从教学逻辑，不是服从并发数。
- 依赖表与 §C 节序不一致（表内节号集合 ≠ §C 节号集合）⇒ 拒收（exit 2）。
- 调度执行体 = `scripts/scheduler.py --work-root "$WORK_ROOT" plan --mode sections --chapter ch##`；
  波次划分 = Kahn 拓扑（波内并行、波间串行），并发度沿用章级授权源。
- 口径 SSOT = `skills/textbook-pipeline-workflow/SKILL.md` §节级并行与恢复协议。

## 4. 鉴别诊断类章节的附加要求

> **学科扩展（B3/ADR-02）**：本节是兽医/医学学科的「鉴别诊断模块」附加要求，
> 非通用判据；其他学科（法学/计算机等）无此概念，直接跳过。权威细则已并入
> `references/profiles/{discipline}.md §5.2`。

若本章属「鉴别诊断模块」（而非疾病个论），额外要求：

- **个论不重复原则**：病原分子机制 / 血清型逐一列举 / 完整基因组结构 / 完整防治体系
  → 改为「详见《XX》[疾病名]节」引用格式，**不得在鉴别模块重复个论内容**。
- **三切入口**：横向鉴别入口 / 场景决策入口 / 综合防控入口，至少覆盖其一。
- **推理链**：重点疾病嵌入 Mermaid 推理链，节点标注**临床依据**（不是抽象描述），
  判断节点 4-8 个。

## 5. 平台 / 模板差异说明

> **学科扩展（B3/ADR-02）**：本节裁剪对象是 profile §5.2 的**学科八要素**
> （要素 4「防治措施」、要素 8「拓展阅读」等均为兽医版要素）；通用兜底四要素的
> 最小集（学习目标/导入案例/理论知识/练习）在任何学科都不再裁剪。
>
> **学段判据 SSOT（#71 批次 2，ADR-02 同构）**：各学段的结构裁剪口径唯一权威源 =
> `references/audience-profiles.md` §1「结构裁剪」列（四档：档位裁剪要素清单 +
> 不可裁要素集）；本节不再复述各档裁剪细则，audience 未声明按回落档
> （audience-profiles §0 默认档，回落须在 issues 声明）。

- 各档裁剪细则 → `references/audience-profiles.md` §1（唯一权威源；含「可裁/不可裁」
  逐档清单）。

> 上述裁剪只影响「必备性」，**五维评分与 80 分红线在任何学段都不豁免**。
