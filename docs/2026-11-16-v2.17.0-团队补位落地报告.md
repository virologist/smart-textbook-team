## 三、三名成员的职责边界（防重叠/防遗漏）

| 相对方 | 边界裁决 |
|---|---|
| learner-advocate vs quality-examiner | 前者判「目标学生读不读得懂/愿不愿读」（受众适配），后者判「专业上对不对/规范上合不合」（内容正确性）；R5 五维无独立可读性维，互补不重叠；同一节可双 blocking，修复单都归 writer |
| learner-advocate vs didactic-architect | 设计侧假设受众 vs 成稿侧验证假设（V 层闭环）；施不改设计稿 |
| standards-alignment vs didactic-architect | 傅生产可判定条目（解析者），陶消费条目做设计决策（设计者）；陶的 1+X 锚以傅映射表为输入 |
| standards-alignment vs literature-scout | 粟检索标准文本 + 核验真伪/现行版本（retrieval-standard 不变），傅只解析**已在本地**的文档；需核验时主理人先派 scout 再派傅 |
| standards-alignment vs quality-examiner | 傅供条目，严执行门禁 3.5 逐条勾稽 |
| assessment-designer vs subject-writer | 祝写正文 + 落资源位占位，秦生成实际考核内容填充；产物分属 draft.md 与 assessment/，秦不回写占位标记 |
| assessment-designer vs quality-examiner | 出题 ≠ 审正文；秦不自审题目，审题由主理人另派严（编排决策） |
| assessment-designer vs learner-advocate | 施可复核题面语言难度，两者互不隶属 |

**遗漏检查**：13 态流水线无职责空白——INTAKE/SPECIFY 有傅标正解析标准，VERIFY/PROOFREAD 有施学露试读，ASSEMBLE/DELIVER 前有秦卷舒配题；三者均为可选增强，由主理人按场景 spawn。
