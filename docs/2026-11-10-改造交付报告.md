## 一、改了什么 & 为什么

### 必须项①：统一 CLI `scripts/stt.py`（新建）
- **问题**：team-lead 里 `EXPERT_DIR` 兜底逻辑（`for r in .workbuddy .codebuddy`）重复 5 处；
  门禁调用分散；spawn 装配是手抄长串命令——易错、难复用、换机首 spawn 死锁零线索。
- **方案**：`stt.py` 从自身 `__file__` 派生包根（不依赖 cwd/环境变量）。薄封装，不重写既有脚本。
  `env` / `gate --phase {design|retrieve|produce|proofread|cross|consistency}` /
  `spawn` / `net-words` / `verify`。
- **接入**：`agents/smart-textbook-team-team-lead.md` 新增「统一 CLI」章节，
  「强制三步」step-1 由内联兜底 + 手抄命令改为 `stt.py spawn` 一行；其余协议原样保留。

### 必须项②：把「文字无检查」缺口转真实检查

| 脚本 | 判据 | 退出码 |

| `check_redlane_registry.py`（红道） | R1–R5 版本六处自洽 / R6 CHANGELOG 顶部须等于当前版本 | 0 / 1 / 2 |

- 门禁 2 的「数据型行」以**含数值**识别，通用层零学科常量（学科词下沉 profiles）。
- 红道检查堵住 `CHANGELOG.md` / `SKILL_CHANGELOG.md` 为 `IMMUNE_FILES` 免检、
  且「SKILL_CHANGELOG 登记」无执行体这两处缺口；权威源与 `package_release.sh` 完全同源。

## 三、验证中抓出并修复的真实缺陷（先验证再宣称）

1. **红道检查读到不存在的路径**：初版读 `root/plugin.json`（真实包无此文件），
   真实插件版本被静默忽略 → 改为读 `.claude-plugin/plugin.json` 等真实权威源。
2. **测试产物污染 repo 扫描门禁**：新测试把产物写进仓库内 `.pytest-tmp/`，
   绝对路径触发学科中立/静态契约 FAIL → 改放 `/tmp`。
3. **兽医学科词写死通用门禁**：`check_gate_retrieval.py` 的触发词表含
   发病率/效价/日龄等，触发学科中立门禁 12 FAIL → 改为学科无关的「含数值」判据。
4. **输入缺失静默吞错**：`check_gate_design.py` 的 `main()` 未处理 `error` 字典，
   文件缺失时打印「0 项未通过」，把「判据没跑」伪装成「判据全过」→
   补 error 分支（exit 2 + 显式报错），并补断言禁止该伪装。
5. **zsh 不拆词导致的两次工具层假绿**：`$FILES` 被当单个文件名、
   `PIPESTATUS` 在 zsh 失效——均改为数组/直接捕获退出码后重验。
